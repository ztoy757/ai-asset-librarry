# AI生成物ライブラリ

AIで生成した画像・音楽・動画を、ひとつの場所にまとめて保管できます。

[はじめる](getting-started.md){ .md-button .md-button--primary }
[対応ファイルを見る](reference/limits.md){ .md-button }

<div class="grid cards" markdown>

-   :material-tray-arrow-down:{ .lg } **まとめて保管**

    ---

    画像・音楽・動画を種類を問わずアップロードでき、PCの容量を圧迫しません。

-   :material-image-multiple:{ .lg } **その場でプレビュー**

    ---

    画像は一覧でそのまま表示、音楽と動画はその場で再生できます。

</div>
