## 対応しているファイル

ファイルの種類（MIMEタイプ）で判定します。

| 種類 | 対象 | 例 |
| --- | --- | --- |
| 画像 | `image/*` | PNG、JPEG、WebP、GIF、SVG |
| 音楽 | `audio/*` | MP3、WAV、FLAC、M4A |
| 動画 | `video/*` | MP4、WebM、MOV |

上記以外（PDF、テキストなど）はアップロードできません。

## 制限

| 項目 | 内容 |
| --- | --- |
| 1ファイルの大きさ | 200MBまで |
| 1回にアップロードできる数 | 1ファイル |
| 空のファイル | アップロードできません |
